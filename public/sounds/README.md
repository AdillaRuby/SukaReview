# Notification sound

Put your notification sound file here as:

```
review-notification.mp3
```

The app looks for exactly this path (`/sounds/review-notification.mp3`). If
the file is missing, playback fails silently — no error, no crash, just no
sound. Any short (1-2s) MP3 works well; keep it under ~200KB so it loads
instantly.

Replace this file with Suka Shawarma's own notification sound whenever it's
ready — no code changes needed.
